# SeismoSignal-Detection

## Overview

SeismoSignal-Detection is a Python-based seismic signal analysis project that investigates how earthquake-related ground motion can be distinguished from background noise using signal processing and energy-based event detection.

The project uses real seismic waveform data from the 29 July 2025 Kamchatka earthquake (magnitude 8.8) recorded at station IU.PET.

## Research Objectives

- Inspect and visualize raw seismic waveform data.
- Apply detrending and bandpass filtering to examine signal characteristics.
- Quantify signal energy using rolling RMS measurements.
- Identify candidate high-energy intervals using a robust statistical threshold.
- Compare observed signal energy with theoretically predicted P- and S-wave arrival times.

## Methodology

1. **Data acquisition:** Retrieve seismic waveform data and earthquake metadata through FDSN data services.
2. **Waveform inspection:** Examine sampling rate, duration, amplitude, and signal structure.
3. **Signal processing:** Detrend the waveform and apply a 1–10 Hz bandpass filter.
4. **Energy analysis:** Calculate RMS energy over 10-second and 5-second windows.
5. **Candidate detection:** Apply a median absolute deviation (MAD)-based threshold to identify high-energy intervals.
6. **Arrival-time comparison:** Compare energy changes with theoretical P- and S-wave arrival predictions.

## Preliminary Results

- Analysed a 660-second waveform sampled at 40 Hz.
- Identified one candidate high-energy interval from 80 to 230 seconds after the waveform start.
- Observed substantially higher RMS energy in the predicted P- and S-wave regions than in the selected pre-arrival baseline.
- Examined the relationship between predicted arrivals and observed waveform energy.

These are preliminary results from a single waveform and should not be interpreted as validated earthquake-detection performance.

## Technologies

Python, ObsPy, NumPy, pandas, SciPy, Matplotlib, scikit-learn, FDSN data services, and Git.

## Limitations and Future Work

- Validate the detector on multiple earthquake and non-earthquake waveforms.
- Investigate instrument response correction and physical amplitude units.
- Evaluate alternative filtering parameters and detection thresholds.
- Quantify detection accuracy, false positives, and missed events.
- Compare energy-based detection with STA/LTA and machine-learning approaches.

## Reproducibility

Install the dependencies listed in `requirements.txt` in a suitable Python environment, then run the analysis modules from the project root.

The downloaded waveform and generated processed data are excluded from version control. The data acquisition script can be used to retrieve the input data; check its configuration before rerunning it.

## Disclaimer

This repository is an exploratory research project. The current threshold-based detector is a proof of concept, not a validated operational earthquake early-warning or detection system.
